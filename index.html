Enterprise SOC Simulation

Capstone #1

Enterprise Security Monitoring and Incident Response Simulation using Splunk, Suricata, Wireshark, Linux, Python and MITRE ATT&CK Framework

Role Tier 1 SOC Analyst
Framework NIST · MITRE
Duration 4–6 weeks

📋 1. Executive Summary

This capstone project simulates the work of a Tier 1 Security Operations Center (SOC) Analyst responsible for protecting a medium-sized enterprise from cyber threats. The project demonstrates how security professionals collect logs, detect attacks, investigate malicious activities, respond to incidents, and recommend security improvements.

The simulation follows the complete Cybersecurity Incident Response Lifecycle:

Preparation Detection Analysis Containment Eradication Recovery Lessons Learned
